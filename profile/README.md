## 🎮 About

NoxelSMP is a survival Minecraft server running on **Folia**, Paper's region-threaded fork, so it stays smooth with many players online. Everything here is the custom tooling we build to run it.

## 🧩 Projects

| Project | What it does | Status |
|---|---|---|
| [**NoxelVotePlugin**](https://github.com/NoxelNetwork/NoxelVotePlugin) | Server-side vote handling with an API, reworked from IRMCTracker for NoxelSMP | Active |
| **NoxelLib** | Shared library powering our plugins | In development |
